# Morphos Capture

React Native CLI app (iOS + Android) — import game film from the camera roll, link it to a calendar event, upload to Morphos, and browse my videos / alerts.

Clips already under the plan duration cap are prepared on-device to H.264 1080p (never upscaled). Games are encoded at 30 fps; skill-clip mode keeps source fps up to 60.

Package ids: `com.morphosanalytics.capture`. Auth redirect: `morphoscapture://auth`.

This is the public Capture app. Backend services stay in private Morphos-Workspace.

## Android preview

```bash
npm run verify:phone-config
npm run android:assemble:release
```

Install `android/app/build/outputs/apk/release/app-release.apk`. CI does the same Gradle assemble on GitHub-hosted `ubuntu-latest` (`arm64-v8a` only).

## iOS

Committed Xcode project: `ios/MorphosCapture.xcodeproj`. CI compiles an **unsigned** `xcodebuild` on GitHub-hosted `macos-latest` (`CODE_SIGNING_ALLOWED=NO`). A signed TestFlight / ad hoc IPA needs Apple certificates stored as GitHub encrypted secrets — never files in git.

End-to-end checklist: [`docs/phone-testing-checklist.md`](./docs/phone-testing-checklist.md).

## Prerequisites

- Portal API reachable from the device (not `localhost`)
- Entra public-client redirect `morphoscapture://auth` (registered on the Morphos tenant)

Runtime config is generated by [`scripts/write-build-config.cjs`](./scripts/write-build-config.cjs) into [`src/generated/buildConfig.ts`](./src/generated/buildConfig.ts) and merged in [`src/config.ts`](./src/config.ts). Unprefixed `PORTAL_*` / `MSAL_*` / `GOOGLE_*` names win when both those and legacy `EXPO_PUBLIC_*` aliases are set.

| Variable | Purpose |
|----------|---------|
| `PORTAL_API_URL` | Portal API base URL (default: `https://api.morphosanalytics.com`) |
| `PORTAL_WEB_URL` | Athlete Portal origin for subscribe-in-browser |
| `MSAL_CLIENT_ID` | Entra athlete portal / mobile public client ID |
| `MSAL_PORTAL_API_SCOPE` | e.g. `api://{portal-api-app-id}/portal.read` |
| `MSAL_TENANT` | Default `common` |
| `GOOGLE_WEB_CLIENT_ID` | Android ID token audience |
| `GOOGLE_IOS_CLIENT_ID` | iOS Google OAuth client |

Copy [`.env.example`](.env.example) to `.env.local` for local overrides, then `npm run write-build-config`.

## Development

```bash
npm install
npm run lint
npm start          # react-native start (Metro)
npm run android    # react-native run-android
npm run ios        # react-native run-ios (Mac)
```

- **Windows Android emulator + Metro in WSL2 (NAT):** `adb reverse` is not enough. Reverse only maps the emulator to **Windows** `127.0.0.1`; WSL2 NAT’s localhost relay drops the JS bundle. Print the WSL eth0 IP (`hostname -I`) and Metro port. In an **Administrator** Windows prompt, proxy that port onto Windows loopback, then reverse it:
  ```bat
  netsh interface portproxy add v4tov4 listenaddress=127.0.0.1 listenport=8081 connectaddress=<WSL-IP> connectport=8081
  adb reverse tcp:8081 tcp:8081
  ```
  Durable alternative: `networkingMode=mirrored` in `%USERPROFILE%\.wslconfig`, then `wsl --shutdown`.
- Morphos Capture is **iOS and Android only**. There is no web app.

App icons live in [`assets/`](./assets/) (`icon.png`, `adaptive-icon.png`, `splash-icon.png`), generated from the Morphos **M** mark via `npm run generate:app-icons` (requires Python 3 + Pillow).

## Signing and Google Sign-In

- The committed `android/app/debug.keystore` is **local debug only** (Gradle alias `androiddebugkey`). Do **not** register its SHA-1 on the Play-facing Google Android OAuth client.
- Play / production Google Sign-In uses the **Play App Signing** SHA-1.
- Preview APKs that should Google-sign-in must be signed with a keystore kept as a GitHub Actions secret, not committed.
- Run `./scripts/print-google-oauth-setup.sh` for package name, bundle ID, and fingerprints.

Apple distribution certificates and provisioning profiles are never committed (`*.p12`, `*.mobileprovision`, `credentials.json`).

## Billing (website only)

Morphos Capture does **not** use Apple In-App Purchase or Google Play Billing. Uploads require an active Morphos subscription purchased on the Athlete Portal (`https://portal.morphosanalytics.com/subscription`) in the **system browser**.
